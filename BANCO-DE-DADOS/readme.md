# 🗄️ Banco de Dados

**`Projeto Escolar`**

Este repositório foi criado para a disciplina de Banco de Dados, reunindo atividades, exercícios e projetos desenvolvidos durante o curso.

## 📚 Sobre a matéria

Banco de Dados é a área da tecnologia responsável por armazenar, organizar e gerenciar informações de forma eficiente. Seu uso é fundamental em sistemas, aplicativos, sites e empresas que precisam lidar com grandes quantidades de dados.

## 🎯 Objetivos

- Compreender os conceitos fundamentais de Banco de Dados;
- Aprender modelagem de dados e relacionamentos;
- Desenvolver consultas utilizando SQL;
- Criar e gerenciar bancos de dados relacionais;
- Aplicar boas práticas na organização das informações.

## 🛠️ Tecnologias e Ferramentas

- MySQL
- SQL
- MySQL Workbench
- Diagramas ER
- Modelo Relacional

## 📂 Conteúdo

- Exercícios práticos
- Modelagem de Banco de Dados
- Diagramas Entidade-Relacionamento (DER)
- Consultas SQL
- Projetos da disciplina
