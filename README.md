# 🎓 ETECVAV - Informática para Internet (AMS)

**`Repositório Acadêmico`**

Este repositório reúne atividades, exercícios, projetos e materiais desenvolvidos durante o curso Técnico em Informática para Internet (AMS) da ETECVAV.

## 📚 Sobre o Curso

O curso de Informática para Internet tem como objetivo formar profissionais capazes de desenvolver soluções para a web, utilizando tecnologias de programação, banco de dados, design de interfaces e metodologias de desenvolvimento.

## 📂 Disciplinas

### 💻 Programação e Algoritmos
Desenvolvimento da lógica de programação, algoritmos e resolução de problemas utilizando linguagens de programação.

### 🌐 Interfaces Web
Criação de páginas e aplicações web utilizando HTML, CSS e JavaScript, com foco em design e experiência do usuário.

### 🗄️ Banco de Dados
Modelagem, criação e gerenciamento de bancos de dados relacionais utilizando SQL e ferramentas específicas.

### 💡 PTIC
Desenvolvimento de projetos, pesquisas e soluções inovadoras aplicando conhecimentos de tecnologia da informação.

### 🎨 Arte Digital
Criação de conteúdos visuais e desenvolvimento da criatividade por meio de ferramentas digitais de design.

## 🛠️ Tecnologias Utilizadas

- Java
- HTML5
- CSS3
- JavaScript
- SQL
- Git
- GitHub

## 🎯 Objetivo do Repositório

Organizar e armazenar os conteúdos produzidos durante o curso, facilitando o acompanhamento da evolução acadêmica e a consulta dos materiais desenvolvidos.
