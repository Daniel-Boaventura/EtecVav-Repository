# 💻 Programação e Algoritmos

**`Projeto Escolar`**

Este repositório foi criado para a disciplina de Programação e Algoritmos, reunindo exercícios, atividades e projetos desenvolvidos durante o curso.

## 📚 Sobre a matéria

Programação e Algoritmos é a base do desenvolvimento de software. Nessa disciplina, aprendemos a criar soluções para problemas utilizando lógica de programação, estruturas de controle e algoritmos.

## 🎯 Objetivos

- Desenvolver o raciocínio lógico;
- Criar algoritmos para resolução de problemas;
- Aprender conceitos fundamentais de programação;
- Utilizar boas práticas na escrita de código;
- Desenvolver aplicações simples e funcionais.

## 🛠️ Tecnologias Utilizadas

- Visual Studio Code
- Git e GitHub
