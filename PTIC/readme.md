# 💡 PTIC

**`Projeto Escolar`**

Este repositório foi desenvolvido para a disciplina de PTIC (Projeto de Transformação e Inovação com Tecnologia da Informação e Comunicação), reunindo atividades, pesquisas e projetos realizados ao longo do curso.

## 📚 Sobre a matéria

A disciplina de PTIC tem como objetivo estimular a criatividade, a inovação e o desenvolvimento de soluções tecnológicas para problemas reais, utilizando conhecimentos adquiridos nas demais áreas do curso.

## 🎯 Objetivos

- Desenvolver projetos com foco em inovação;
- Trabalhar em equipe e aprimorar a comunicação;
- Aplicar conhecimentos de tecnologia na prática;
- Planejar, organizar e executar projetos;
- Buscar soluções para desafios do cotidiano.

## 🛠️ Ferramentas Utilizadas

- Git e GitHub
- Canva
- Figma
- Ferramentas de produtividade
- Tecnologias estudadas no curso

## 📂 Conteúdo

- Pesquisas

- Protótipos

- Atividades da disciplina
