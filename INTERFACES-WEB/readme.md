# 🌐 Interfaces Web

**`Projeto Escolar`**

Este repositório foi desenvolvido para a disciplina de Interfaces Web, reunindo atividades, exercícios e projetos voltados à criação de páginas e aplicações para a web.

## 📚 Sobre a matéria

Interfaces Web é a área responsável pelo desenvolvimento da parte visual e interativa dos sites. Nela, aprendemos a criar páginas organizadas, responsivas e agradáveis para os usuários.

## 🎯 Objetivos

- Desenvolver interfaces modernas e funcionais;
- Aplicar conceitos de design e usabilidade;
- Criar páginas responsivas para diferentes dispositivos;
- Utilizar tecnologias fundamentais do desenvolvimento web;
- Melhorar a experiência do usuário.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Figma
- Git e GitHub

## 📂 Conteúdo

- Estruturação de páginas web
- Estilização com CSS
- Interatividade com JavaScript
- Design Responsivo
- Projetos e atividades da disciplina
