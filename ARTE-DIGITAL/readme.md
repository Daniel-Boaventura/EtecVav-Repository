# 🎨 Arte Digital

**`Projeto Escolar`**

Este repositório foi desenvolvido para a disciplina de Arte Digital, reunindo atividades, pesquisas e projetos relacionados à criação visual utilizando ferramentas digitais.

## 📚 Sobre a matéria

A Arte Digital é uma forma de expressão artística produzida com o auxílio de tecnologias e softwares. Ela está presente em áreas como design gráfico, ilustração, animação, publicidade, jogos digitais e produção de conteúdo para a internet.

## 🎯 Objetivos

- Desenvolver a criatividade e a expressão visual;
- Aprender conceitos de design e composição;
- Utilizar ferramentas digitais para criação artística;
- Produzir projetos visuais para diferentes mídias.

## 🛠️ Ferramentas Utilizadas

- Canva
- Photoshop
- Illustrator
- Figma
- Ferramentas online de edição de imagem

## 📂 Conteúdo

- Atividades da disciplina
- Projetos práticos
- Pesquisas
- Exercícios de design
